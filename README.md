# SupplyChainIQ: Autonomous Supply Chain Decision Agent

An agentic AI decision system built for inventory monitoring, stockout prediction, and automated procurement planning. Developed for the hackathon Mission 02.

## Project Structure
- `main.py`: The core agent loop combining deterministic math tools with Gemini AI reasoning.
- `utils.py`: Deterministic math functions calculating lead-time demand and stockout risks.
- `data.json`: Mock inventory and supplier dataset.
- `requirements.txt`: Project dependencies.
